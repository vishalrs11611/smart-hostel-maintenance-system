# Case study plan

## Title
AI-Assisted Agile Software Engineering and Project Management: Smart Hostel Maintenance System

## Research question
How can Agile planning, Git-based version control, automated testing, and responsibly reviewed AI assistance improve the traceability and quality of a small Flask application?

## Method
1. Establish the working Flask prototype as the baseline.
2. Record requirements and acceptance criteria in Jira.
3. Link implementation branches and commits to Jira issue keys.
4. Develop in short iterations and review changes through pull requests.
5. Run automated tests and CI checks.
6. Maintain an AI usage log with human verification.
7. Evaluate results against functional requirements and documented limitations.

## Evidence to collect
- Jira epics, backlog, sprint plans, issue status history.
- GitHub commits, branches, pull requests, and Actions runs.
- Test cases, test output, and defect records.
- Screenshots of the running application.
- AI usage log and reviewer notes.

## Evaluation measures
- Requirement-to-issue-to-commit traceability.
- Number of test cases executed and passed.
- Defects found and corrected.
- Features completed versus planned.
- Qualitative observations on where AI assistance helped or required correction.

## Integrity note
Do not report target outcomes as achieved results. Capture actual project dates, test results, sprint outcomes, and limitations during execution.
